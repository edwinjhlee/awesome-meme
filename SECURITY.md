| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

This repository stores only YAML metadata and a Python/shell renderer — no sensitive data, credentials, or user information.

If you discover a security issue:

* **Renderer vulnerabilities** (command injection, path traversal in template handling) — please open a GitHub issue or contact the maintainer directly.
* **Image URL issues** (malicious redirects, inappropriate content) — report the meme ID and we'll remove or replace the URL.

We aim to respond within 48 hours.
